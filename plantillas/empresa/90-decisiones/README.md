## Reglas

- El titulo es el problema resuelto, no el tema: `0007-usar-contraentrega-en-vez-de-pasarela.md`.
- **Un ADR aceptado no se edita.** Si cambia la decision, se escribe uno nuevo que la supersede y el viejo solo cambia su linea de estado.
- Obligatorio: las alternativas descartadas y las consecuencias en contra. Sin eso, el ADR no sirve para nada.
