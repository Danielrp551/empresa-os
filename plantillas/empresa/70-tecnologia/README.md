# 70 — Tecnologia

Los sistemas que sostienen la operacion.

## Que vive aqui

- `arquitectura.md` — que sistemas hay y como se conectan
- `credenciales.md` — INVENTARIO: que credencial existe, para que, donde se regenera, cada cuanto rota, en que archivo de `secrets/` vive. **Nunca los valores.**
- `integraciones/` — como se habla con cada plataforma, con sus trampas conocidas
- `scripts/` — automatizaciones propias
- `tools/` — herramientas de terceros vendorizadas, con su version fijada

## Que NO vive aqui

Los valores de las credenciales. Esos viven solo en `secrets/`, que nunca se versiona (regla 13).
