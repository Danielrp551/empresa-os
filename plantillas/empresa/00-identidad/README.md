- `logo.svg`, `logo-cuadrado.png`, `favicon.png` — los entregables de marca
- `dominios-y-cuentas.md` — dominios, redes, handles, quien es titular de cada uno
- `naming.md` — evidencia de disponibilidad del nombre, con fechas
