# 50 — Operacion

Como funciona el dia a dia y que hacer cuando algo se rompe.

## Que vive aqui

- `METODOLOGIA-*.md` — los procesos operativos repetibles
- `runbooks/` — procedimientos para ejecutar bajo presion
- `proveedores/{nombre}.md` — ficha: que hace, condiciones, contacto, problemas conocidos
- `incidentes/YYYY-MM-DD-*.md` — postmortems sin culpa
- `division-del-trabajo.md` — la auditoria de que es automatizar, delegar y solo-humano
- `CHECKLIST-*.md` — las colas de tareas solo-humano

## Que NO vive aqui

Los procesos de adquisicion de clientes (van en `60-crecimiento/`).

## Skills relacionadas

`/incidente`, `/checklist-humano`, `/metodologia-nueva`
