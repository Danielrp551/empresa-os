# Plantillas de documento

Una por arquetipo. Si dudas cuál usar, la pregunta es **qué propósito cumple el documento**, no de qué tema trata.

| Necesitas... | Plantilla | Tipo |
|---|---|---|
| Escribir cómo se hace un proceso repetible | [`metodologia.md`](metodologia.md) | Metodología |
| Abrir una corrida concreta (campaña, test, proyecto) | [`tablero.md`](tablero.md) | Unidad de trabajo |
| Registrar un checkpoint de esa corrida | [`revision.md`](revision.md) | Unidad de trabajo |
| Cerrar la corrida con veredicto y aprendizajes | [`cierre.md`](cierre.md) | Unidad de trabajo |
| Registrar por qué se eligió algo | [`decision.md`](decision.md) | Decisión |
| Documentar algo que se rompió hacia afuera | [`incidente.md`](incidente.md) | Caso especial |
| Delegar un tramo de trabajo a otra sesión | [`brief-sesion.md`](brief-sesion.md) | Caso especial |
| Listar lo que solo puede hacer la persona | [`checklist-humano.md`](checklist-humano.md) | Caso especial |
| Fichar un proveedor, producto o entidad | [`ficha-entidad.md`](ficha-entidad.md) | Referencia |
| Mapear piezas generadas a su ID en la plataforma | [`indice-activos.md`](indice-activos.md) | Referencia |
| Guardar una investigación con fuentes | [`investigacion.md`](investigacion.md) | Conocimiento |
| Validar una apuesta grande antes de construir | [`prfaq.md`](prfaq.md) | Estrategia |

**La regla que resuelve casi todas las dudas:** ¿esto va a seguir siendo cierto en la corrida siguiente? Sí → metodología. No → unidad de trabajo.
